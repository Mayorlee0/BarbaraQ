# Barbara’s Mini Love Quest 💘

A tiny romantic canvas game built with vanilla HTML, CSS, and JavaScript.

## How to Run
- Open `index.html` in a browser.
- Or deploy as a static site (Vercel-ready).

## Controls
- Desktop: Arrow keys or WASD
- Mobile: On-screen D-pad or swipe on the canvas
- Sound: Toggle the Sound button in the HUD

Collect all 7 heart tokens, unlock the Valentine Gate, and answer the final question!
